## 2. U2 case definition and expected outcome

`scripts/run_url_fetch_isolation.py`, `controls()`:

```python
"U2": {"label": "private payload, valid permission",
       "expected_full": "allow",
       "make_view": lambda p: base_view(
           priv(p), records=[_record("allow", "auth.a1")],
           fields=PII_FIELDS, retrieved=PII_RETRIEVED,
           directory=RESOLVED, allowlist=["localhost"],
           declared=["vic.full_name", "vic.passport_no"])},
```

(verbatim, `scripts/run_url_fetch_isolation.py:145-151`)

`expected_full` is `"allow"` — full_gateway allowing U2 **is** the expected outcome. U2 is the authorized-share control: a permission covering all matched fields + resolved destination + purpose exists, so M3 must permit it. (U1 removes that permission → expected block; U3 adds an applicable deny → expected block under deny-wins.)
