Generated by `scripts/export_prompts.py` (read-only on results/; no model calls).

**System prompt:** none. Every run sent exactly one user-role message at turn 0 (`run_planner_pilot_v1.call_planner`, `run_multistep_pilot.call_turn`); the `tool_schema` text is embedded in that message.

**Byte identity:** prompts are reconstructed from the frozen template + fixture; traces did not store prompt text. Runner scripts and fixtures hash-match FREEZE.md (docs/run_config.md §hashes), so the reconstruction is what the runs sent. Multistep follow-up `*.feedback.json` files are copied verbatim from `feedback_sent` in traces.json; the model's own intermediate replies are stored truncated (400 chars) in the traces and are not reproduced.

`planner_pilot_v2_adapter11` sent no prompts — it replays saved v2 model outputs through adapter-1.1.

**Caveats.** (1) Follow-up messages sent after `binding_reject` / `adapter_reject` / malformed turns were generated by `planner_feedback()` but not stored in traces (`feedback_sent` is recorded only after gateway blocks), so they are absent here — this affects all multistep_pilot (v1) MS-ID1 / MS-LC* episodes.
